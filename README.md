# مسابقة الأسئلة

تطبيق مسابقات بتصميم إسلامي حديث يعمل على أي كمبيوتر من المتصفح، ويُثبّت كتطبيق مستقل.

## للمدير (جهازك)
1. افتح رابط التطبيق، ثم ⚙ الإعدادات ← **النشر للأجهزة**.
2. اكتب **كلمة سر المسابقة**، ثم الصق **مفتاح النشر (Token)**.
3. عدّل الأسئلة والصور والإعدادات كما تريد.
4. اضغط **نشر للأجهزة الآن**. تصل الأسئلة لكل الأجهزة خلال دقيقة إلى دقيقتين.

### إنشاء مفتاح النشر (مرة واحدة)
github.com ← صورتك ← Settings ← Developer settings ← Personal access tokens ← **Fine-grained tokens** ← Generate new token
- Repository access: **Only select repositories** ← اختر هذا المستودع
- Permissions ← Repository permissions ← **Contents: Read and write**

المفتاح يُحفظ على جهازك فقط ولا يُنشر.

## لكل كمبيوتر عرض
**الطريقة الأولى (ملف تثبيت لويندوز):** نزّل [setup-musabaqa.zip](https://kaqsrfav2002-cloud.github.io/musabaqa/setup-musabaqa.zip)، فك الضغط، وشغّل `Setup-Musabaqa.bat`. تظهر أيقونة «مسابقة الأسئلة» على سطح المكتب.

**الطريقة الثانية:** افتح رابط التطبيق في Chrome أو Edge واضغط **⬇ تثبيت التطبيق**.

ثم أدخل كلمة سر المسابقة مرة واحدة.

بعدها يفتح التطبيق من سطح المكتب، ويحمّل آخر الأسئلة تلقائياً، ويعمل بدون إنترنت بآخر نسخة حمّلها.

## الأمان
ملف الأسئلة `data/quiz.enc.json` مشفّر (AES-256) بكلمة سر المسابقة، فلا يقرؤه من يفتح المستودع.
